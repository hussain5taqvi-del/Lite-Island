# LiteIsland website

One static page (`index.html`) with a live, working copy of the island (music, clock/weather, calendar, system, drag a file -> QR). Nothing to build.

1. Open `index.html`, fill `CONFIG` near the bottom (trial link, buy link, contact email).
2. Upload the whole folder to Cloudflare Pages (free, unlimited static bandwidth): Workers & Pages > Create > Pages > Upload assets.
3. Put that one link in your Instagram / Facebook bio.
